# Manuscript File Guide

## Current freeze

- `final/SongCi_AICSS2026_Final_Anonymous.pdf` is the frozen double-blind submission PDF.
- `final/SongCi_AICSS2026_Final_Anonymous.docx` is its editable source.
- `final/SongCi_AICSS2026_Final_Author_Copy.pdf` is the author-identified backup PDF.
- `final/SongCi_AICSS2026_Final_Author_Copy.docx` is its editable source.

Do not upload the author copy to a double-blind review field.

## Earlier snapshot

`SongCi_unified_current.docx` and `.pdf` predate the 2026-09-04 freeze. They are retained because they already exist in repository history. They contain author identity, use a longer 32-page layout, and are not current submission files.
